# Güreş

## Proje hakkında

*Güreş Rehberi*, güreş türlerini anlaşılır biçimde tanıtan basit ve erişilebilir
bir web sitesidir. Projenin hedef kitlesi, güreşe yeni ilgi duyan lise ve
üniversite öğrencileridir.

Sitede beş güreş türü tanıtılır: Yağlı Güreş (Kırkpınar), Karakucak Güreşi,
Aba Güreşi, Serbest Stil Güreş ve Greko-Romen Güreş. Ziyaretçi, içerikler
sayfasındaki arama alanıyla güreş türlerini başlığına göre anında bulabilir.

## Özellikler

- Üç sayfalı site ve her sayfada ortak navigasyon menüsü
- Beş güreş türünü tanıtan içerik kartları
- Başlığa göre anlık arama (yazdıkça filtreleme)
- Sonuç sayacı ve "sonuç bulunamadı" mesajı
- Temizle düğmesi
- Harf büyüklüğünden ve baştaki/sondaki boşluklardan etkilenmeyen arama
- Mobil uyumlu (responsive) tasarım ve klavye ile erişilebilir arayüz

## Proje dosya yapısı

```text
Gures-Rehberi/

```

## Yerel bilgisayarda çalıştırma

1. Depoyu bilgisayara indirin veya klonlayın:

   ```bash
   git clone https://github.com/huzeyfex/gures.git
   ```

2. Proje klasörünü açın.
3. `index.html` dosyasını bir web tarayıcısında açın.
4. Menüden *İçerikler* sayfasına geçerek başlığa göre anlık aramayı
   deneyebilirsiniz. Proje için ayrıca bir sunucu veya paket kurulumu
   gerekmemektedir.
